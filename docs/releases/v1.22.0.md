# FileDock 1.22.0

- 普通标签、右上角固定入口和视图模式增加连贯的选中底板过渡；只移动装饰层，保持点击和拖放区域稳定，刘海两侧分别处理。
- 工具栏与路径悬停反馈使用统一节奏；连续切换合并自动滚动请求，旧请求不会把位置拉回。悬停当前工作区不再重复刷新或清空选择。
- 加载提示延迟显示并保留最短停留时间，快速读取不再闪现，连续批次保持稳定；窗口隐藏后立即清理。
- 音乐文字切换到悬停控制时保留滚动位置，返回后继续，隐藏期间停止滚动动画。
- 动效速度沿用现有设置，并遵守系统减少动态效果。拖拽、窗口移动和开合期间暂停附加动效；文件列表不参与批量布局动画，不新增页面截图或常驻逐帧计时器。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。保留现有配置、应用身份与更新签名。
