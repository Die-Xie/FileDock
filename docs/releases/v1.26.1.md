# FileDock 1.26.1

- 补齐文件拖出自动收起后的返回：继续同一次拖动，回到刘海或当前设置的边角即可重新展开面板，继续在标签、收藏或暂存中放置文件。
- 返回使用原有展开延迟和触发区域判定，点按刘海唤醒模式也支持；保留副屏、全屏与黑名单例外，仅快捷键模式不会自动展开。
- 仅允许刚才引起自动收起的同一个文件拖动返回；松手、取消、切换会话或手动开合后清除权限，避免过期拖动误呼出。
- 拖出收起和拖回展开由「设置 → 文件与工作区 → 拖放文件 → 拖出文件时自动收起面板」统一控制，默认开启。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。当前发行包已签名，尚未经过 Apple 公证。
