# FileDock 1.27.0

- 「设置 → 呼出与交互 → 自动呼出例外」新增行为选择：命中全屏或应用黑名单时，可继续停用鼠标呼出，或临时改用点按呼出。
- 点按模式暂停悬停，只在普通左键点击当前刘海／所选触发边角时展开；离开例外环境后自动恢复原有方式，正常呼出设置保持不变。
- 默认保留现有禁用行为；仅快捷键模式、设置／模态窗口及拖动保护继续生效，副屏按原配置准入。
- 点击位置使用事件中的屏幕坐标，避免点击后移动鼠标导致错误判定或在另一块屏幕展开；带修饰键的点击留给前台应用。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。当前发行包已签名，尚未经过 Apple 公证。
