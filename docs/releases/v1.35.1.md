# FileDock 1.35.1

- 打磨「刘海延展」展开曲线：柔和起步，略微超过目标尺寸后自然回落，文件内容保持稳定。
- 预留透明绘制空间，避免过冲被裁切；可见尺寸、文件位置及保存的面板大小保持一致。
- 连续开合从当前轮廓衔接；接近全开时不重复整段回弹，尾部收束不阻止自动收回。
- 保留动画速度和减少动态效果设置；其他触发位置与拖放路由沿用 1.35.0。

## English

- Refines Notch Extension motion with a softer start and one subtle size overshoot that settles naturally while file content stays stable.
- Reserves transparent backing space to prevent clipping without changing the visible panel size, file positions or saved dimensions.
- Reverses from the current contour, avoids replaying the rebound near full size and allows automatic dismissal during the settling tail.
- Preserves animation speed and Reduce Motion preferences. Other trigger positions and file-drop routing retain the 1.35.0 behavior.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple.
