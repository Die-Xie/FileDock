# FileDock 1.17.0

- 新增「设置 → 音乐」连接面板，直接显示 QQ 音乐安装、运行和 FileDock 授权状态。
- 未授权时一键打开辅助功能设置；返回 FileDock 后自动重新检测，已有授权不再重复请求。
- 连接异常时提供「打开主窗口并重连」，并保留单独的重新检测入口。
- 嵌入式音乐栏未连接时可点击直达音乐设置；已连接时可右键进入。底部播放栏新增设置按钮。
- 授权列表缺少当前应用时，可一键在访达中显示 FileDock，方便添加正确的应用。
- 面板隐藏时仍可在音乐设置中完成配置；设置关闭、最小化或隐藏后停止该入口的轮询。

继续沿用 `local.diexie.filedock` 应用标识和原固定签名证书。macOS 的授权开关及触控 ID 仍需用户本人确认，应用不会自动修改系统隐私授权。

macOS 13+，Apple Silicon / Intel 通用版本；采用固定本地证书签名，未进行 Apple 公证。
