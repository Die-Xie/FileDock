# FileDock 1.21.0

- 新增 QQ 音乐、系统“音乐”、网易云音乐的手动选择和自动切换。后台检测已运行的播放器，控制绑定播放器及进程，切换时取消旧命令；不变的播放状态不会重复刷新界面。
- 新增文件右键菜单与暂存区的 AirDrop 入口，支持多选文件和文件夹。系统面板选择接收方，完成或取消后恢复 FileDock 原窗口；共享期间保留文件访问，退出与升级等待完成。
- 「设置 → 通用 → 文件」可开启或关闭 AirDrop，开关随配置保存。
- 修复收藏、暂存分批加载尚未完成时，拖动重排可能丢失未加载引用的问题；重排基于完整引用清单，保留筛选外与未读项目。
- 修复配置导入与后台文件操作冲突，统一新增、编辑、导入的容量限制，避免创建下次无法加载的配置。
- 系统可选文件类型描述读取失败时，降级读取关键属性，仍正确识别文件夹与应用包。
- 自定义工作区图标改为有界后台读取、限尺寸解码和缓存，减少切换与界面刷新中的同步磁盘工作。

系统音乐首次连接需确认 macOS 自动化权限；已有 QQ 辅助功能授权与配置继续保留。网易云音乐使用客户端公开的原生菜单与窗口信息，尚未实机验收，客户端布局不匹配时会给出连接提示。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。沿用固定本地签名，尚未经过 Apple 公证。
