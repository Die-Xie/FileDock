# FileDock 1.19.2

- 「关于」页使用正式 FileDock 应用图标，与系统和应用程序中的图标一致。
- 修复打开设置时刘海嵌入面板顶部被菜单栏遮挡的问题：主面板保持刘海位置、尺寸和层级，设置及其弹窗显示在它上方。
- 统一设置、颜色面板、文件对话框、预览和更新界面的层级，支持嵌套弹窗与原始层级恢复。
- 移除只对两侧按钮增加空白的旧补偿，避免音乐和文件区跳动；不改变固定状态或保存的窗口尺寸。
- 补充位置保持、弹窗优先级、重复切换、异常恢复及外部窗口层级变更的回归检查。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。沿用既有应用与更新签名身份。
