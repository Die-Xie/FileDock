# FileDock 1.20.0

- 大目录改为浅层流式枚举，分批显示已读文件，不必等待整个目录读取完毕；文件视图和缩略图继续按需加载。
- 超时改为检测连续无读取进展，正常读取较久不会因总时长超过 5 秒被终止；系统确实无响应时保留已显示内容，仍可切换工作区和重试。
- 复用本次扫描预取的文件元数据，排序移到后台并缓存，减少重复磁盘查询、主线程排序和无变化刷新造成的重绘；耗时目录自动降低定时刷新频率。
- 应用程序及可执行插件包只显示图标与基本信息，不再交给内嵌或空格 Quick Look 生成预览；文档包继续支持预览。
- 保留原有配置、代码签名及更新签名身份；补充万项目录、渐进读取、取消/超时和略览策略回归测试。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。
