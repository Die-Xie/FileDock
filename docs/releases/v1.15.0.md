# FileDock 1.15.0

原生 macOS 文件工作区，作者：Diexie。

- 软件正式更名为 **FileDock**，保留已有配置与签名身份。
- 暂存区支持任意本地文件、文件夹和文稿包，也支持原始图片、网页图片及其他应用提供的临时文件。临时内容先安全保存，再加入暂存；清空暂存只移除引用。
- Finder 修改文件夹颜色、标签或自定义图标后，FileDock 自动同步外观。
- 定时目录扫描移到后台，批量暂存与窗口尺寸保存合并写入，回收不再使用的书签，并保护配置不被超限数据覆盖。
- 修复音乐轮询期间首次控制点击被丢弃，以及导入照片的 EXIF 旋转、镜像方向问题。
- 保留刘海与四角触发、可调动画与延迟、嵌入式音乐控制、可排序工作区、路径导航和文件预览。液态玻璃使用固定深色质感，纯色主题继续适配明暗。

**验证：**23 组回归测试通过；同机单次基准中暂存 500 个真实文件从 3.2252 秒降至 0.2135 秒。此数字衡量批量操作耗时，不代表动画帧率。已知待改进项见[质量审查](https://github.com/Die-Xie/FileDock/blob/v1.15.0/docs/QUALITY_REVIEW.md)。

**安装：**下载 `FileDock.zip`，解压后替换 `/Applications/FileDock.app`。支持 macOS 13 及以上，包含 Apple Silicon 与 Intel 架构；原生液态玻璃需要 macOS 26。当前应用采用固定本地证书签名，未进行 Apple 公证。已安装用户继续使用原有配置目录与授权身份。

`SHA256SUMS.txt` 可校验本版本 ZIP、发布说明和源码提交号。源码采用 Apache 2.0 许可证。
