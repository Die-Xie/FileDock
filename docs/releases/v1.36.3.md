# FileDock 1.36.3

- 固定底部项目计数的宽度，筛选结果数量或选中文件数变化时，类型筛选条不再跟着移动。
- 类型筛选条靠右对齐，紧凑模式切换「全部」与清除按钮时，「…」菜单入口保持原位。
- 保留 1.36.2 的顶部、底部标签与文件内容微动画，以及缓存和保存性能优化。

## English

- Reserves a stable footer count width so changing filter results or file selections no longer shifts the type filter.
- Aligns the type filter to the trailing edge, keeping the More menu anchor fixed when compact controls switch between All and Clear.
- Retains the tab, filter and file-content micro-animations and performance improvements from 1.36.2.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple.
