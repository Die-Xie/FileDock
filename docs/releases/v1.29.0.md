# FileDock 1.29.0

- 支持把 Finder 或 FileDock 中的文件夹拖到顶部标签之间、标签边缘或首尾空白处，直接在指定位置创建新标签；可一次添加多个文件夹。
- 新建位置显示蓝色插入细线、文件夹加号和松手提示；现有标签中央保留悬停切换和文件投放。
- 创建标签只引用原文件夹，不复制或移动文件；松手后才在后台检查文件夹与准备访问权限，保存后重启保留。
- 加入整批校验、超时及并发上限；无效目录或过期插入目标不会产生部分标签，也不会转成文件移动。
- 保留软件内拖动开始时的文件类型提示，避免跨标签后普通文件被误判；中英文操作说明同步更新。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。当前发行包已签名，尚未经过 Apple 公证。
