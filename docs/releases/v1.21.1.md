# FileDock 1.21.1

- 将 AirDrop 快捷入口放到顶部收藏旁，统一图标尺寸与间距。
- 直接发送所选文件；在暂存区未选项目时发送全部暂存引用，其他情况下打开文件与文件夹选择器。
- 保留「设置 → 通用 → 文件 → 启用 AirDrop」开关与文件右键入口。
- 新增「＋ → 固定最近使用到右上角」选项；时钟入口支持点击、悬停切换和右键取消固定，取消后恢复原标签顺序。
- 窄刘海面板为全部快捷按钮保留空间，宽度不足时沿用安全区域下的完整工具栏。
- 保留 1.21.0 的多播放器、数据完整性与性能优化；QQ 音乐和系统音乐的连接已获实机确认。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。沿用固定本地签名，尚未经过 Apple 公证。网易云音乐尚未实机验收。
