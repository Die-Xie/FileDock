# FileDock 1.21.2

- 将「最近使用」与收藏、暂存统一放入「＋」菜单的可勾选功能组，去掉上方重复的独立「最近使用」入口。
- 勾选「固定最近使用到右上角」即可启用时钟入口；首次开启自动准备内容，已有最近使用工作区会直接复用。
- 更新使用指南和应用内帮助，保留现有固定设置、工作区与取消固定行为。
- 支持把 Finder 或 FileDock 的文件直接拖到 AirDrop 图标，悬停高亮并显示松手提示；松手直接进入系统接收设备选择，不再打开文件选择器。
- AirDrop 拖放使用发送语义，保留原文件及暂存引用；未选择文件时点击按钮只显示当前界面内的拖入提示。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。沿用现有应用及更新签名身份。
