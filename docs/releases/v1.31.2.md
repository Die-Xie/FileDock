# FileDock 1.31.2

- 修复紧凑标签快速连续悬停时，切换后自动滚动取消下一次悬停计时的问题。
- 悬停选择的标签已在视口内，不再重复执行选中标签滚动或重置鼠标位置基准；未选中的刘海另一侧片区不再取消当前悬停任务。
- 鼠标进入下一个目标时取消旧的排队滚动，保留正常的悬停延迟；点击和键盘选择仍会展示选中的标签，真实布局变化仍保持静止鼠标保护。
- 保留左右统一的 30 点图标宽度和 4 点间距，以及原有文件拖放与窗口拖动行为。

## English

- Fixes rapid consecutive hovers on compact tabs being interrupted when post-selection scrolling cancels the next hover timer.
- Hover-selected tabs are already visible, so selection no longer repeats reveal scrolling or resets the pointer baseline. An unrelated header segment on the other side of the notch no longer cancels the active hover.
- Entering the next target cancels queued scrolling while honoring the configured hover delay. Click and keyboard selections still reveal their tabs; actual layout changes retain stationary-pointer protection.
- Keeps the matching 30-point icon widths, 4-point spacing, file drag-and-drop and window dragging behavior.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple. Existing settings and workspaces are preserved.
