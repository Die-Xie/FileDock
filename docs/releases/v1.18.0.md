# FileDock 1.18.0

支持文件框选与拖动文件时悬停切换工作区，修复嵌入模式顶部遮挡和快捷入口裁剪。

- 收藏与暂存入口使用完整的固定布局空间，暂存数量角标包含在测量边界内；嵌入模式为整个控制组预留宽度，避免图标或角标被裁剪。
- 拖动文件时，悬停顶部工作区标签、收藏或暂存图标可切换目标。沿用工作区悬停延迟，最短 0.15 秒；关闭普通悬停切换时，拖拽悬停仍以 0.35 秒启用。
- 重复的拖拽更新不会重置计时或反复刷新当前工作区；离开目标、结束拖拽、隐藏面板和重新排列标签时取消待触发的切换。
- 悬停只切换视图，不会移动或导入文件。松手到文件夹标签时放入工作区根目录，合集标签添加引用；最近使用可悬停浏览，仍不接受直接写入。暂存入口继续支持直接拖入引用及临时内容。
- 保留标签拖动排序及文件拖出行为，沿用 1.17.1 的后台目录加载与读取超时机制。
- 网格、列表和分栏的当前文件区支持从空白处拖出选择框。Shift 添加选择，Command 反选，Esc 取消并恢复框选前的选择；文件图标仍用于拖动文件。
- 修复快速查看、设置和模态窗口打开期间，嵌入模式降低层级后顶部工具栏被菜单栏遮住的问题。低层级期间留出安全距离，返回面板后恢复原布局；边角和独立窗口不增加间隙。

新增拖拽悬停时序、框选响应与隔离、菜单栏避让及真实图标渲染边界测试。沿用应用标识与固定签名证书。macOS 13+，Apple Silicon / Intel 通用版本。
