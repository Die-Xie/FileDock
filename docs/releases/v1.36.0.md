# FileDock 1.36.0

- 新增文件类型筛选，默认提供 MD、PDF、ZIP、文件夹，常用类型可自定义并保存。
- 底部「…」可查看当前面板包含的全部类型与数量；窄面板也可使用。
- 类型、颜色标签和名称搜索可叠加；快捷类型收在紧凑分段条中，字号统一，项目数量独立显示。
- 复用已载入的文件信息和缓存，大目录分批载入时同步补全类型，切换目录或工作区后清除类型筛选。

## English

- Adds file-type filtering with MD, PDF, ZIP and Folder shortcuts by default. Customize and save your preferred types.
- The footer “…” menu offers every file type present in the panel, including on narrow layouts.
- Combine type, color and name filters. Type shortcuts share a compact segmented bar with consistent typography; item counts remain separate.
- Uses loaded metadata and cached counts, updates during progressive loading and clears the type filter when navigating to another folder or workspace.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple.
