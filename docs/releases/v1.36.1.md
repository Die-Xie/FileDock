# FileDock 1.36.1

- 恢复可见边缘的窗口缩放与光标提示，适配刘海延展的透明动画画布。
- 窄窗口保持刘海两侧的单行标签栏，标签与快捷入口可横向滚动，不再把整栏挤到下方。
- 类型栏仅显示当前面板实际存在的类型；缺少常用类型时以其他现有类型补位，保留自定义优先顺序。
- 增加一键「全部」清除类型筛选；窄面板也可直接清除当前类型。
- 关闭菜单或选择类型后，短暂保留面板以便鼠标返回；回到面板后恢复原有收起延迟。
- 拖放完成后保留相关项目的选中高亮，便于定位重新排序或转移后的文件。

## English

- Restores resizing and cursor feedback at the visible window edges, including the transparent Notch Extension animation canvas.
- Keeps notch-side tabs and shortcuts in one horizontally scrollable row on narrow windows instead of pushing the toolbar down.
- Type shortcuts show types actually present in the panel, filling missing favorites with other available types while preserving custom priorities.
- Adds a direct All button to clear the type filter, with a clear action on narrow panels too.
- Keeps the panel open briefly after menu interaction so the pointer can return, then restores the configured dismissal delay.
- Retains selection highlighting after drops so reordered or transferred files are easier to locate.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple.
