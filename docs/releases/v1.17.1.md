# FileDock 1.17.1

修复切换工作区时整个应用卡住的严重问题。

- 卡死现场采样显示：标签悬停切换调用同步目录扫描，主线程持续等待系统打开目录。将首次载入、标签切换、目录导航和手动刷新统一改为后台加载，最近使用的文件信息也通过该加载器读取。
- 增加 5 秒读取超时和可重试提示；错误不再以阻塞导航的弹窗报告，仍可切换工作区或收起窗口。
- 限制实际未完成读取最多 3 个；取消和超时不会错误释放仍被系统阻塞的工作槽位，避免重试无限堆积。
- 使用请求代次及工作区上下文拒绝过期结果；路径跳转成功后才提交历史，失败后重试仍指向原目标。
- 路径显示和手动排序不再在界面求值期间重复读取目录名称或解析符号链接。

新增故意阻塞读取的回归测试，检查界面线程响应、超时、切换恢复、历史、重试、取消及并发上限。基础模型语义测试使用隔离的即时加载器，真实异步加载路径另行测试。

保持应用标识与签名证书。macOS 13+，Apple Silicon / Intel 通用版本，未进行 Apple 公证。
