# FileDock 1.19.0

- 新增「设置 → 更新」和菜单中的检查更新入口，可主动下载、安装并重新启动；可选择每日自动检查。
- 更新源和安装包均有签名校验，升级沿用固定应用身份；文件转移、暂存导入结束后才重启。
- 修复标签间文件拖放、Finder 或标签文件拖入收藏失败；收藏仅添加引用，按住 ⌥ 向文件夹拖入为复制。
- 新增拖放目标高亮、同目录及跨标签细线插入位置，并在转移后保存对应顺序；提供松开前的复制／移动／引用提示，收紧并统一右上角按钮间距。
- 修复拖拽会话残留，恢复后续拖放和图标刷新；补齐批量导入超时、迟到回调、父子文件与引用迁移处理。
- 同步 Finder 文件夹的颜色标签、自定义图标及已支持的 Tahoe 符号元数据；图标读取和分栏父目录扫描移出主线程。
- 改善预览入口的主线程开销，并检查迟到的预览索引请求。
- 改善开合、加载和切换时的闪动：保留已有缩略图，限制后台预览并发，短暂加载不再挤动文件区，最近访问的工作区可立即显示缓存。
- 从刘海拖出时先保持音乐和顶部布局，松开后再平滑切换；未固定时隐藏右上角关闭按钮。重新设计菜单栏文件夹收纳槽图标。
- 将 Diexie 当前偏好作为新安装默认值：液态玻璃、刘海嵌入、零呼出/收回延迟、1.3 倍动画速度、音乐/收藏/暂存入口开启，以及按修改日期降序混排。保留已有用户配置，不包含个人文件路径或授权数据。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。应用使用固定本地证书签名，尚未经过 Apple 公证。自动检查默认关闭，安装由用户决定。
