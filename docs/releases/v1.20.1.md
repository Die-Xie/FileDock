# FileDock 1.20.1

- 「最近使用」的元数据提取和文件验证移到后台，加入取消、无进展超时、真实并发上限和手动重试，避免慢文件阻塞界面。
- 相同的最近使用通知不再反复取消正在进行的文件扫描；分栏父目录也使用后台排序和渐进显示。
- 粘贴、新建、重命名和移到废纸篓改为后台执行，纳入文件任务上限及退出/升级等待；切换工作区或改选文件不会被迟到结果覆盖。
- 批量拖入普通文件夹时合并配置保存，暂存路径使用有明确失效规则的缓存；统一父子文件去重逻辑。
- 修复界面发布耗时造成的旧计时值误判，以及无关路径重建造成的选择状态丢失。
- 保持现有工作区、偏好、签名和授权身份；补充并发、取消、粘贴目标锁定与批量保存测试。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。
