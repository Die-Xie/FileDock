# FileDock 1.35.0

- 恢复统一的原生文件拖放路由，修复颜色接收层可能遮挡文件排序、跨标签投放和拖文件夹创建标签的问题。
- 直接拖入颜色圆点时按落点赋色，普通文件夹接收移动或复制，并修复外部拖放后的撤销焦点。
- 扩充空白区域右键菜单，提供新建文件夹、简介、视图、排序、分组及显示选项等操作。
- 修复工作区拖动或分享后可能无法自动收起的问题，并为动画结束回调增加超时恢复。
- 修复主线程延迟时文件可能无法拖起的问题，并避免缺少准确插入位置时误改顺序。
- 新增可选「刘海延展」样式；保留明暗与材质选择及系统减少动态效果设置。

## English

- Restores one native file-drop route, preventing color targets from blocking file reordering, cross-tab drops and folder-tab creation.
- Applies the destination color on direct color-button drops, respects allowed move or copy operations and restores undo focus after external drops.
- Expands the empty-area context menu with folder creation, information, view, sorting, grouping and display options.
- Fixes cases where workspace dragging or sharing could prevent automatic dismissal, and recovers from missing animation completion callbacks.
- Keeps file drags responsive during delayed event handling and avoids changing order when the insertion position is unavailable.
- Adds an optional notch extension while preserving appearance, material and Reduce Motion preferences.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple. Existing settings and workspaces are preserved.
