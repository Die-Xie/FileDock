# FileDock 1.26.2

- 支持把文件、文件夹及多选项目从 FileDock 拖到 Dock 的系统废纸篓，松手后移入废纸篓，可在访达中恢复。
- 从收藏和暂存拖到废纸篓同样处理原文件；成功后同步移除相关引用和旧书签。暂存区的清空／移除操作仍只移除引用。
- 使用拖动开始时捕获的完整文件批次，切换标签、收起面板或改变选择不会更改删除对象；取消、普通复制／移动和迟到重复回调不会额外删除文件。
- 实际移入在后台执行，部分失败会保留对应引用并提示原因；保留拖出收起、拖回当前刘海或边角展开的行为。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。当前发行包已签名，尚未经过 Apple 公证。
