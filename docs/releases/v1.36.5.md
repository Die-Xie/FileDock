# FileDock 1.36.5

- 修复在空白处右键选择“添加项目”后，文件选择窗口闪跳或意外消失、主面板无法自动收回的问题。
- 修复文件名悬停组件的原生鼠标进入／退出回调异常，避免打断文件选择器及其他窗口交互。
- 菜单操作在菜单退出后执行，避免选择器和菜单同时接管焦点；关闭选择器后恢复正常收回计时，并保留短暂的鼠标返回时间。
- 仅真实的面板拖动会触发自动固定；弹窗造成的系统窗口通知不会改变固定状态。
- 保留已有拖放、撤销／重做、悬停提示和切换动画。

## English

- Fixes the Add Items picker flashing or unexpectedly disappearing after a background context-menu action and leaving the main panel unable to hide automatically.
- Corrects native mouse-enter and mouse-exit callbacks in filename hints, preventing exceptions from interrupting file pickers and other window interactions.
- Runs menu actions after menu tracking ends. Closing a picker resumes the normal hide countdown, with a short interval to return the pointer to the panel.
- Only a real panel drag can trigger automatic pinning; system window notifications from a picker do not change the pin state.
- Retains file drops, undo/redo, filename hints and transition animations.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple.
