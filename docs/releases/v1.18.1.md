# FileDock 1.18.1

- 修复 SVG 拖入暂存区时被当作位图解码而报错的问题。本地文件 URL 保留引用；临时文件表示和仅提供数据的 SVG 保留原始矢量文件与扩展名，不转成 PNG。其他文稿在缺少文件表示时也可回退到原始数据表示。
- 调整快速查看层级：嵌入面板继续覆盖菜单栏，Quick Look 位于主面板之上。设置和模态窗口继续按独立的避让策略显示，预览也纳入模态窗口协调。
- 拖拽悬停切换工作区期间，优先显示已缓存图标；未缓存项目使用轻量文件类型图标，并暂停新的缩略图请求，避免同步读取自定义图标阻塞拖拽。松手后恢复实际图标与缩略图，临时图标不进入文件修订缓存。
- 保留 1.18.0 的文件框选、拖拽悬停导航、角标布局和 1.17.1 的后台目录读取。
- 列表视图可点击名称、修改日期、种类和大小列标题排序；再次点击同列切换升降序并显示方向指示。手动顺序切换到列排序时清除当前目录的手动覆盖，最近使用根目录仍保持最近打开时间顺序。

补充 SVG 原文件/临时文件/仅数据提供方、图标轻量显示后恢复和预览层级回归测试。沿用应用标识和固定签名证书。macOS 13+，Apple Silicon / Intel 通用版本。
