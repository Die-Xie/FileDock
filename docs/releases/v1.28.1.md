# FileDock 1.28.1

- 「设置 → 呼出与交互 → 呼出方式」新增“鼠标进入比例”，可在 1%–200% 间连续调节，一键恢复默认 75%。
- 1%–100% 按鼠标可见面积判定；超过 100% 需要完全进入后继续向刘海内部移动，200% 要求到达屏幕顶边，中间值按剩余可移动深度计算。
- 悬停、点按及同一次文件拖动返回刘海使用同一设置；无刘海屏幕的顶部中央和边角触发不受影响。
- 屏幕之外不可见的光标像素不计入面积，确保 100%–200% 仍可触达；调节后重新计时，保留手动收起保护及原有配置。
- 中英文说明同步更新，滑动期间仅更新界面草稿，结束后保存。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。当前发行包已签名，尚未经过 Apple 公证。
