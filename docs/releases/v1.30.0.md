# FileDock 1.30.0

- 文件右键菜单新增系统颜色标签；文件夹新增“自定义文件夹”，支持图案、表情、图片和恢复系统图标，变化同步到 Finder。
- 补齐显示简介、压缩、制作副本、制作替身和终端入口。简介使用 Finder 自己的窗口，副本使用系统原生操作，替身为真实 Finder 别名文件。
- 按 Finder 的含义区分“复制”（生成副本）和“拷贝”（剪贴板），支持 ⌘D、⌘I、⌘L；原有复制粘贴、拖放、共享和暂存保持。
- 文件操作在后台执行，同名输出不覆盖，失败清理临时结果；切换目录后不抢回选择。样式更改立即刷新图标与目录缓存，元数据编辑不再产生无关配置写入。
- 图片导入限制文件大小和解码尺寸，读取超时与迟到结果互相隔离；新增中英文、明暗两套外观下的样式编辑窗口回归。

首次使用“显示简介”可能需要在 macOS 提示中允许 FileDock 控制访达。系统扩展和第三方快速操作请通过“在访达中显示”进入 Finder 使用。

支持 macOS 13 及以上，提供 Apple Silicon / Intel 通用版本。当前发行包已签名，尚未经过 Apple 公证。
