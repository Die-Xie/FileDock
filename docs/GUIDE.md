# FileDock 使用指南

[← 返回产品介绍](../README.md)

## 安装与更新

从 [最新 Release](https://github.com/Die-Xie/FileDock/releases/latest) 下载 `FileDock.zip`，解压后将 `FileDock.app` 放入「应用程序」，再从这里启动。支持 macOS 13 及以上，通用版本包含 Apple Silicon 与 Intel 架构。

当前发行包使用固定本地证书签名，尚未经过 Apple 公证。更新时先退出应用，再替换 `/Applications/FileDock.app`；保留本机配置，并避免留下多个可启动副本。需要登录启动时，在稳定安装位置启用。

## 呼出、固定与收起

在「设置 → 通用」中选择触发位置。刘海、顶部中央与四角都可作为入口；刘海触发可选择悬停或点按唤醒，点按开关不影响边角触发。

- **悬停延迟**：0–1500 毫秒；0 表示进入有效区域后立即触发。
- **移开后收起延迟**：0–3000 毫秒；返回面板会取消倒计时。
- **动画速度**：「设置 → 外观 → 动画」中调节 0.5×–2.0×，或选择速度预设。
- **固定窗口**：从顶部空白处拖出面板会自动固定，也可使用右下角图钉。文件区用于拖放文件，边缘可调整窗口大小。

真实刘海以系统箭头可见面积判定进入程度，至少 75% 进入后才开始悬停计时。拖拽、调整大小、打开设置或对话框时，自动收起会暂停。

菜单栏图标左键切换面板，右键可打开设置、帮助与退出菜单。关闭面板后应用仍在菜单栏运行。

## 工作区、收藏与最近使用

点击右上角 **＋** 添加文件夹工作区或创建文件引用合集。拖动顶部标签可改变顺序，右键标签可编辑、移除或切换「仅显示图标」。

**文件夹工作区**直接浏览实际目录。**文件引用合集**把不同位置的项目放在一起；移除引用不会删除原文件。收藏是常用的引用合集，默认固定在右上角星标入口，右键可隐藏，通过加号菜单可恢复。

**＋ → 最近使用**可添加虚拟工作区，最近打开的文件排在前面。它使用系统 Spotlight 索引，最多显示 500 项；结果受索引与文件提供方影响，可能与 Finder 的「最近使用」不同。根目录支持搜索、预览和拖出，不接收拖入或手动排序。

收藏和暂存的固定入口支持悬停切换，沿用工作区的悬停切换延迟。

拖着文件悬停在顶部标签、收藏或暂存入口，也可切换到目标工作区，再把文件拖入内容区。拖拽悬停最短为 0.15 秒；即使关闭普通悬停切换，拖拽悬停仍以 0.35 秒启用。悬停本身只切换视图，不处理文件；离开目标或结束拖拽会取消待触发的切换。

## 文件暂存区

把文件拖到暂存区，或在文件右键菜单中选择暂存，可以收集任意类型的本地文件、文件夹与文稿包。入口可在「设置 → 通用 → 文件」或加号菜单中关闭，暂存内容会继续保留。

![暂存区的文件收集与转移流程](assets/filedock-staging.png)

- **本地文件**：保存引用，文件仍在原位置。
- **网页图片、临时文件**：先保存到本机，再加入暂存。导入位置为 `~/Library/Application Support/FileDock/Staged Imports/`。
- **批量复制 / 移动**：选择目标文件夹后转移，成功项目移出暂存，失败项目保留，同名文件自动改名。
- **拖出到其他应用**：可以使用暂存中的文件，引用仍会保留，可按需手动移除。
- **清空暂存**：只移除引用，不删除原文件，也不会删除已经保存的导入文件；可右键在访达中定位这些文件。

## 浏览与文件操作

网格、列表、分栏三种视图可随时切换。分栏右侧直接预览选中文件，并支持滚动阅读；空格可打开快速查看。预览格式取决于系统 Quick Look 及已安装的扩展，无法预览时可用默认应用打开。

点击导航栏中的任一级路径即可跳转，长路径可横向滚动。收藏合集内的文件夹可通过合集名称返回根部；前进、后退保留导航历史。

### 拖放规则

| 操作位置 | 行为 |
| --- | --- |
| 拖入文件夹工作区 | 默认移动，按住 **Option** 则复制 |
| 拖入合集根目录 | 添加引用 |
| 松手到顶部文件夹 / 合集标签 | 放入该工作区根目录 / 添加引用；文件夹默认移动，Option 复制 |
| 在当前目录或合集中拖动项目 | 调整显示顺序，不改变文件的实际位置 |
| 将选中文件拖到访达或其他应用 | 提供所选文件，由目标应用处理 |

支持 ⌘ 单击多选、Shift 连续选择和多文件拖放。文件名冲突会自动改名，移到废纸篓需要确认。排序菜单可从手动顺序切回名称、日期等自动排序。Finder 中的文件夹颜色、标签与自定义图标会随面板刷新同步。

从文件区空白处按住鼠标拖动可框选多个文件；Shift 框选追加，⌘ 框选反选，Esc 恢复框选前的选择。空白处单击清空选择，图标本身继续用于拖动文件。

图片可以拖入文件夹并保存为 PNG；网页下载不使用浏览器登录状态。输入图片上限为 32 MiB，单边最多 8192 像素，总像素最多 2400 万。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| ⌘⌥↓ | 在设置的触发位置呼出 / 收起 |
| ⌘⌥→ | 在光标附近呼出 |
| ⌘H | 收起面板 |
| ⌘↑ | 返回上级，并选中刚离开的文件夹 |
| ⌘↓ | 进入选中的文件夹，或打开选中的文件 |
| ⌘[ / ⌘] | 按历史后退 / 前进，也可用 ⌥← / ⌥→ |
| ⌘⇧[ / ⌘⇧] | 切换工作区 |
| 空格 | 快速查看 |
| ⌘C / ⌘V | 复制 / 粘贴文件 |
| ⌘⌥C | 复制路径 |

两组全局呼出快捷键可在「设置 → 快捷键」中重新录制、清除或恢复默认。录制时需包含 ⌘、⌃ 或 ⌥ 中的至少一种；Esc 取消，Delete 清除。注册冲突会在设置中提示。

搜索框和文档预览获得焦点时，保留它们原生的键盘操作。

## 连接 QQ 音乐

打开「设置 → 音乐」，连接页会显示**安装、运行、授权**三项状态，并提供对应操作入口。

1. 安装并打开 QQ 音乐，保持其主窗口可用。
2. 首次使用时，在连接页打开授权设置，在「系统设置 → 隐私与安全性 → 辅助功能」中允许 **FileDock**；系统验证需本人完成。
3. 返回 FileDock，连接状态会自动重检。若列表中没有 FileDock，可从连接页显示当前应用，手动加入授权列表。

授权完成后，刘海嵌入布局的中央显示曲名和歌手，超长内容自动滚动；悬停时显示播放控制。其他布局使用底部播放栏。系统开启「减少动态效果」时，曲名不滚动。

连接异常时，可从设置中打开 QQ 音乐主窗口再重连。嵌入音乐栏未连接时点击、已连接时右键，均可进入音乐设置；底部播放栏提供设置入口。QQ 音乐界面更新、关闭主窗口或切换迷你播放器，都可能影响连接。

重新连接只重试读取，不重复请求系统授权。保持同一应用标识与签名身份更新通常可沿用授权；更换电脑、丢失签名身份或重置系统隐私权限后，可能需要重新授权。FileDock 不保存收听记录。

## 外观与自动呼出例外

「设置 → 外观」可选择液态玻璃或纯色主题。液态玻璃固定使用深色半透明外观，不随系统明暗切换；macOS 26 使用原生玻璃，较早系统使用系统模糊材质。纯色主题支持跟随系统、浅色和深色。系统开启「减少透明度」时使用实色背景。

在「设置 → 通用 → 自动呼出例外」中加入游戏、播放器等应用，可在其位于前台时暂停鼠标自动呼出。也可启用「全屏时暂停鼠标呼出」；自定义无边框全屏若无法识别，建议直接把应用加入黑名单。快捷键与菜单栏仍可手动呼出。

## 本机数据与隐私

配置位于 `~/Library/Application Support/FileDock/config.json`，包含工作区路径、书签与设置，文件权限为 `0600`。导出的配置也包含路径和书签，适合作为本机备份。最近使用的查询结果仅保存在内存中，不写入配置与导出文件。

FileDock 不包含遥测、订阅或账号服务。只有用户拖入网页图片 URL 时，才会发起对应的网络下载。
