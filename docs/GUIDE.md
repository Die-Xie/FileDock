# FileDock 使用指南

[← 返回产品介绍](../README.md)

## 安装与更新

从 [最新 Release](https://github.com/Die-Xie/FileDock/releases/latest) 下载 `FileDock.zip`，解压后将 `FileDock.app` 放入「应用程序」，再从这里启动。支持 macOS 13 及以上，通用版本包含 Apple Silicon 与 Intel 架构。

当前发行包使用固定本地证书签名，尚未经过 Apple 公证。更新时先退出应用，再替换 `/Applications/FileDock.app`；保留本机配置，并避免留下多个可启动副本。需要登录启动时，在稳定安装位置启用。

## 设置分类

设置采用侧栏导航：**通用**管理启动、菜单栏及配置备份；**呼出与交互**管理触发位置、延迟、全屏例外和应用黑名单；**文件与工作区**集中配置收藏、最近使用、暂存、AirDrop及排序。主题、尺寸和正常界面动效位于**外观**；另外保留**快捷键、音乐、关于**。关于页包含软件更新。侧栏底部始终提供「退出 FileDock」；退出会保存配置，并等待进行中的文件传输完成。

呼出、收起与工作区悬停延迟均支持无刻度滑块和毫秒输入；鼠标调节结束后合并保存。设置页切换不改变已保存偏好。趣味爪印动画已移除，旧配置仍可导入。

## 呼出、固定与收起

在「设置 → 呼出与交互」中选择触发位置。刘海、顶部中央与四角都可作为入口；刘海触发可选择悬停或点按唤醒，点按开关不影响边角触发。

- **悬停延迟**：0–1500 毫秒；0 表示进入有效区域后立即触发。
- **移开后收起延迟**：0–3000 毫秒；返回面板会取消倒计时。
- **动画速度**：「设置 → 外观 → 动画」中调节 0.5×–2.0×，或选择速度预设。
- **固定窗口**：从顶栏任意空白处按住拖出面板会自动固定，也可使用右下角图钉。标签、音乐控件和右上角按钮保留各自操作；文件区用于拖放文件，边缘可调整窗口大小。

真实刘海以系统箭头可见面积判定进入程度，至少 75% 进入后才开始悬停计时。面板移动、标签排序、框选、调整大小、打开设置或对话框时，自动收起会暂停；文件拖出可按下述偏好收起。

菜单栏图标左键切换面板，右键可打开设置、帮助与退出菜单。关闭面板后应用仍在菜单栏运行。

## 工作区、收藏与最近使用

点击右上角 **＋** 添加文件夹工作区或创建文件引用合集。拖动顶部标签可改变顺序，右键标签可编辑、移除或切换「仅显示图标」。

**文件夹工作区**直接浏览实际目录。**文件引用合集**把不同位置的项目放在一起；移除引用不会删除原文件。收藏是常用的引用合集，默认固定在右上角星标入口。取消固定或右键隐藏后，收藏会完全隐藏，不再变成普通标签；收藏内容仍保留，通过加号菜单可恢复。其他文件引用合集不受影响。

在 **＋** 菜单勾选 **固定最近使用到右上角**，即可开启最近使用时钟入口，最近打开的文件排在前面。它使用系统 Spotlight 索引，最多显示 500 项；结果受索引与文件提供方影响，可能与 Finder 的「最近使用」不同。根目录支持搜索、预览和拖出，不接收拖入或手动排序。元数据查询在后台完成；若系统无响应会提示重试，自动轮询不会反复创建任务。

收藏和暂存的固定入口支持悬停切换，沿用工作区的悬停切换延迟。

「设置 → 呼出与交互 → 延迟与切换」支持0–1500ms连续调节，无刻度，0表示关闭普通悬停切换。读数显示毫秒；拖动结束后保存，重启保留细分数值。文件拖拽时的悬停跳转保持独立的最短延迟，避免误触。

右上角收藏、AirDrop、最近使用与暂存图标支持拖动调整顺序。把图标拖到另一图标左侧或右侧，或这组图标的最前、最后，看到细线后松手即可。普通工作区标签也支持间隙与首尾插入；刘海两侧和滚动区域各自保持可见范围。排序不切换工作区、不操作文件。顺序会自动保存，关闭再开启某功能时仍保留其位置。「＋」和收起按钮始终位于这些功能图标之后。

工作区与视图模式切换时，选中底板平滑移动；刘海两侧独立过渡。顶部标签和路径自动滚动会合并连续请求，只定位到最后选中的项目。悬停在当前工作区不再重复刷新，点击标签返回根目录的行为保持不变。

很短的文件读取或操作不显示加载提示；超过约150ms才显示，显示后至少停留约220ms，连续批次共享同一提示，隐藏窗口立即清理。界面反馈速度在「外观 → 界面动画速度」调整。拖拽、窗口移动、开合期间暂停附加动效；系统启用「减少动态效果」时关闭位移动效。歌曲信息在悬停控制时暂停滚动，返回后继续原来的位置。

首次开启会自动准备最近使用内容；已有最近使用工作区时则直接复用。取消固定后会隐藏最近使用，不再转为普通标签；工作区和内容仍保留，重新勾选即可恢复。右键时钟也可关闭此入口；关闭时若正在查看最近使用，会切换到其他可用工作区。它支持点击和悬停切换，最近使用继续保持只读。

拖着文件悬停在顶部标签、收藏或暂存入口，也可切换到目标工作区，再把文件拖入内容区。拖拽悬停最短为 0.15 秒；即使关闭普通悬停切换，拖拽悬停仍以 0.35 秒启用。悬停本身只切换视图，不处理文件；离开目标或结束拖拽会取消待触发的切换。

## 文件暂存区

把文件拖到暂存区，或在文件右键菜单中选择暂存，可以收集任意类型的本地文件、文件夹与文稿包。入口可在「设置 → 文件与工作区」或加号菜单中关闭，暂存内容会继续保留。

![暂存区的文件收集与转移流程](assets/filedock-staging.png)

- **本地文件**：保存引用，文件仍在原位置。
- **网页图片、临时文件**：先保存到本机，再加入暂存。导入位置为 `~/Library/Application Support/FileDock/Staged Imports/`。
- **批量复制 / 移动**：选择目标文件夹后转移，成功项目移出暂存，失败项目保留，同名文件自动改名。
- **拖出到其他应用**：可以使用暂存中的文件，引用仍会保留，可按需手动移除。
- **清空暂存**：只移除引用，不删除原文件，也不会删除已经保存的导入文件；可右键在访达中定位这些文件。

### AirDrop 与共享

把 Finder 或 FileDock 中的文件直接拖到收藏旁的 **AirDrop** 图标，看到高亮和“松开以通过 AirDrop 发送”提示后松手，即可进入系统接收设备选择界面，无需再次选择文件。拖放只发送文件，不移动原文件或改变暂存内容。

也可以先选择文件再点击 AirDrop；在暂存区未选项目时会发送全部暂存引用。未选文件的普通点击只在当前界面提示拖入，不弹出文件选择器。文件右键菜单也可选择 **AirDrop…**。支持本地文件、文件夹及文稿包，一次最多 1000 项。

在 **＋** 菜单勾选或取消 **启用 AirDrop**，即可开启或关闭此功能；它与「设置 → 文件与工作区」中的同名选项同步，默认开启。关闭后隐藏 AirDrop 入口，普通共享菜单也不再提供 AirDrop；已开始的共享会继续到完成或取消。

FileDock 在后台检查项目可访问性，再交给系统 AirDrop 面板；接收方由你选择。系统发送界面出现时 FileDock 暂时隐藏，完成或取消后恢复原窗口位置、尺寸和固定状态。检查失败或超时会提示，取消不会自动重发。普通“共享…”也会保留文件访问与服务对象，直到所选系统服务结束。退出和升级等待共享完成。

## 浏览与文件操作

网格、列表、分栏三种视图可随时切换。分栏右侧直接预览选中文件，并支持滚动阅读；空格可打开快速查看。预览格式取决于系统 Quick Look 及已安装的扩展，无法预览时可用默认应用打开。应用程序和可执行插件包仅显示图标与基本信息，不生成 Quick Look 内容；双击或点击打开按钮仍可主动启动应用。

大目录会先显示首批已读取项目，再逐步补全列表。排序、搜索和文件操作可使用当前显示内容；读取过程中不会因为总时间超过 5 秒就报超时。若系统连续无响应，会保留已显示的内容并提供重试入口，可随时切换工作区。较慢目录会降低后台刷新频率，手动刷新和文件操作后的刷新仍会立即发起或合并排队。

粘贴、新建、重命名和移到废纸篓会在后台处理。操作期间可切换工作区，退出或升级会等待实际写入完成。

点击导航栏中的任一级路径即可跳转，长路径可横向滚动。收藏合集内的文件夹可通过合集名称返回根部；前进、后退保留导航历史。

### 系统剪贴板

在 Finder 用 **⌘C** 复制文件或文件夹，再在 FileDock 的目标工作区用 **⌘V** 粘贴。FileDock 文件区也支持 **Ctrl+C / Ctrl+V**，并提供「编辑 → 复制 / 粘贴」和文件区空白处的「粘贴」菜单；搜索、重命名等输入框沿用系统文本编辑行为。

- **文件夹**：复制文件到当前目录，同名项目自动改名，原文件保留。
- **收藏、文件引用合集和暂存区**：添加原文件引用，不移动文件，重复引用自动合并。
- **剪贴板图片**：可粘贴截图及复制的 PNG、TIFF 等图片；先保存到本机私有暂存目录，再加入引用或复制到目标文件夹。SVG 和 PDF 的原始文稿表示保留为对应文件，不当作位图解码。清空暂存仅移除引用。

读取和图片保存均在后台完成，粘贴目标以按下快捷键时的位置为准；切换标签不会改变目标。读取期间剪贴板被替换、内容不支持或超时会提示，不使用后来的内容。最近使用保持只读；纯文本及普通网页地址不会自动变为文件或触发下载。一次最多读取 20000 个文件，包含图片数据的批次最多 128 项，单项数据不超过 32 MB、总数据不超过 64 MB，图像尺寸仍遵守导入限制。

### 拖放规则

| 操作位置 | 行为 |
| --- | --- |
| 拖入文件夹工作区 | 默认移动，按住 **Option** 则复制 |
| 拖入合集根目录 | 添加引用 |
| 松手到顶部文件夹 / 合集标签 | 放入该工作区根目录 / 添加引用；文件夹默认移动，Option 复制 |
| 在当前目录或合集中拖动项目 | 调整显示顺序，不改变文件的实际位置 |
| 将选中文件拖到访达或其他应用 | 提供所选文件，由目标应用处理 |

「设置 → 文件与工作区 → 拖放文件」提供 **拖出文件时自动收起面板**，默认开启。从 FileDock 拖着文件离开面板后，按「呼出与交互 → 鼠标移开后收起」的延迟隐藏面板，继续保持拖动即可放到原先被遮挡的应用或桌面区域；0 ms 表示离开即收起。计时期间返回面板会取消收起。固定面板同样适用，收起不改变固定状态。

收起后继续同一次拖动，把文件拖回当前设置的触发位置，会按展开延迟重新打开面板：刘海模式回到刘海，四角模式回到所选边角。点按刘海唤醒模式下也不必放开文件再点按。仍使用原来的副屏准入、刘海进入比例、全屏和黑名单例外；仅快捷键模式不会自动展开。松手、取消拖动、换一次拖动或手动开合后，旧的返回权限立即失效。关闭该选项后，拖动期间面板保持显示；面板内拖放、跨标签悬停和从 Finder 拖入的行为保持不变。

拖动时会显示目标虚线和“松开以复制／移动／添加引用”提示。停在顶部标签上会切换工作区，可继续移到文件区放下，或直接在标签上松开。同一目录重排和跨工作区拖入都以细实线指示插入位置，放下后保存该顺序。在子文件夹中央释放会放入该文件夹，两侧用于排序插入；收藏和暂存始终只添加引用。

支持 ⌘ 单击多选、Shift 连续选择和多文件拖放。文件名冲突会自动改名，移到废纸篓需要确认。排序菜单可从手动顺序切回名称、日期等自动排序。Finder 中的文件夹颜色、标签与自定义图标会随面板刷新同步。

从文件区空白处按住鼠标拖动可框选多个文件；Shift 框选追加，⌘ 框选反选，Esc 恢复框选前的选择。空白处单击清空选择，图标本身继续用于拖动文件。

列表视图可直接点击列标题排序，再次点击同一列切换升降序；箭头指示当前方向。SVG 作为原始矢量文件暂存，不会转成位图。

排序菜单和「设置 → 文件与工作区」中的“文件夹优先”可控制是否把文件夹排在前面。关闭后文件与文件夹按同一列混排；手动顺序和最近使用不受影响。

图片可以拖入文件夹并保存为 PNG；网页下载不使用浏览器登录状态。输入图片上限为 32 MiB，单边最多 8192 像素，总像素最多 2400 万。

搜索框和文档预览获得焦点时，保留它们原生的键盘操作。

## 连接音乐播放器

打开「设置 → 音乐」，选择 **QQ 音乐、音乐（macOS 自带）、网易云音乐**或**自动选择**。连接页显示**安装、运行、授权**三项状态。自动模式优先选择正在播放的应用；多个同时播放时保持当前选择，只检测已运行的应用。升级前的 QQ 音乐选择保留，新安装默认为自动选择。

1. 安装并打开需要的播放器；QQ 音乐保持其主窗口可用。
2. 首次使用时按连接页提示授权。QQ 和网易云音乐需要「隐私与安全性 → 辅助功能」中的 **FileDock**；系统音乐需要允许 FileDock 自动化控制“音乐”。被拒绝后可到「隐私与安全性 → 自动化」重新开启；系统验证需本人完成。
3. 返回 FileDock，连接状态会自动重检。若列表中没有 FileDock，可从连接页显示当前应用，手动加入授权列表。

授权完成后，刘海嵌入布局的中央显示曲名和歌手，超长内容自动滚动；悬停时显示播放控制。其他布局使用底部播放栏。系统开启「减少动态效果」时，曲名不滚动。

连接异常时，可从设置中打开播放器主窗口再重连。嵌入音乐栏未连接时点击、已连接时右键，均可进入音乐设置；底部播放栏提供设置入口。QQ 音乐界面更新、关闭主窗口或切换迷你播放器，都可能影响连接。

网易云音乐通过客户端的原生播放菜单控制，仅在动作唯一且可用时执行；若客户端未提供该菜单，会显示连接异常。曲名来自客户端提供的播放窗口标题，无法读取时仍可显示连接状态与可用控制。不同客户端版本的菜单和标题格式可能不同，1.21.0 尚未完成网易云音乐的实机验收。

重新连接只重试读取，不重复请求系统授权。保持同一应用标识与签名身份更新通常可沿用授权；更换电脑、丢失签名身份或重置系统隐私权限后，可能需要重新授权。FileDock 不保存收听记录。

系统“音乐”能够提供真实播放位置和时长时，歌曲下方显示细进度条，嵌入和底部播放栏均支持；QQ、网易云音乐以及未知时长的内容不显示轨道或占位提示。进度条只展示进度，不接收点击或拖动跳播。暂停时停止走动；面板隐藏时停止附加动画，连续读取中断后最多平滑推进5秒。

## 外观与自动呼出例外

「设置 → 外观」可选择液态玻璃或纯色主题。液态玻璃固定使用深色半透明外观，不随系统明暗切换；macOS 26 使用原生玻璃，较早系统使用系统模糊材质。纯色主题支持跟随系统、浅色和深色。系统开启「减少透明度」时使用实色背景。

在「设置 → 呼出与交互 → 自动呼出例外」中加入游戏、播放器等应用，可在其位于前台时暂停鼠标自动呼出。也可启用「全屏时暂停鼠标呼出」；自定义无边框全屏若无法识别，建议直接把应用加入黑名单。快捷键与菜单栏仍可手动呼出。

## 检查与安装更新

从菜单栏选择「检查更新…」，或打开「设置 → 关于」中的软件更新区域（1.19.0 为独立「更新」页）。发现新版后可查看说明、下载并安装；完成后重新启动，保留本机工作区与设置。文件传输、暂存导入或正在进行的拖动结束前，会推迟安装重启。

每日自动检查默认关闭，可在更新设置中开启；不会自动安装。更新源与安装包均验证签名，校验失败不安装。1.19 以前的版本需要先手动更新到支持此功能的版本。

检查失败时可再次检查，或通过「查看发行版本」手动下载；展开「错误详情」可查看具体网络或校验原因。发布中的短暂不可用不代表没有新版本，也不会降低签名校验要求。

## 本机数据与隐私

配置位于 `~/Library/Application Support/FileDock/config.json`，包含工作区路径、书签与设置，文件权限为 `0600`。导出的配置也包含路径和书签，适合作为本机备份。最近使用的查询结果仅保存在内存中，不写入配置与导出文件。

FileDock 不包含遥测、订阅或账号服务。拖入网页图片 URL 时会发起对应下载；手动检查更新或开启每日检查后，会访问 GitHub 的更新源，确认安装时下载新版安装包。更新不发送系统配置统计。
