# FileDock 1.34.0

- 设置侧栏的“退出 FileDock”与其他条目的图标和文字对齐。
- 调整快捷键组合符号的视觉间距，保持按键录制与现有快捷键不变。
- 液态玻璃新增浅色和跟随系统选项；升级时保留原有深色玻璃，纯色主题的外观偏好单独保存。
- 悬停切换改为独立开关，0 ms 表示立即切换。旧版以 0 ms 关闭悬停的配置会保留关闭状态；文件拖放时仍可悬停切换。

## English

- Aligns Quit FileDock with the other settings sidebar icons and labels.
- Improves spacing between shortcut symbols while preserving recording and existing shortcuts.
- Adds light and system-following appearances for Liquid Glass. Existing installations retain dark glass, and the solid theme keeps its own appearance preference.
- Uses a separate hover-switching toggle, with 0 ms meaning immediate selection. Legacy configurations that used 0 ms to disable hover remain disabled; drag-hover switching remains available.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple. Existing settings and workspaces are preserved.
