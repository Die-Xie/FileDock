# FileDock 1.31.1

- 左侧仅图标工作区与右上角快捷入口统一为 30 点宽、4 点间距，左右边距及图标中心间距一致。
- 仅图标标签的选中背景与右侧保持一致；带名称的标签保留原有文字布局。
- 同步更新刘海两侧的空间测量，保持标签拖动、插入引导、滚动和窗口拖动区域正确。

## English

- Aligns icon-only workspace tabs with the top-right shortcuts using 30-point widths and 4-point gaps, matching outer margins and icon-center spacing.
- Matches icon-only selection backgrounds to the shortcuts while retaining named-tab text layout.
- Updates header measurements on both sides of the notch to preserve tab dragging, insertion indicators, scrolling and window drag regions.

Requires macOS 13 or later. Universal build for Apple Silicon and Intel. Signed, not yet notarized by Apple. Existing settings and workspaces are preserved.
