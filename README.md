# FileDock

原生 macOS 文件工作区。作者：**Diexie**。

[下载最新版本](https://github.com/Die-Xie/FileDock/releases/latest) · [质量与性能 Review](docs/QUALITY_REVIEW.md) · [发布流程](docs/RELEASING.md)

## 安装

从 Releases 下载 `FileDock.zip`，解压后将 `FileDock.app` 放入「应用程序」。支持 Apple Silicon 与 Intel，最低 macOS 13；液态玻璃在 macOS 26 使用原生效果。当前发行包采用固定本地证书签名，未进行 Apple 公证。更新时替换同一安装位置，并保留本机配置与签名身份。

## 项目结构

```text
Sources/       原生应用、文件模型、拖放、预览、主题与音乐控制
Resources/     Info.plist、独立应用图标及图标生成源
Tests/         使用隔离文件和模拟后端的回归测试
scripts/       签名初始化与发布工具
docs/          质量审查与发布说明
.github/       Release 工作流
build.sh       构建并验证应用签名
test.sh        运行测试
```

构建产物、缓存、个人配置和签名私钥不进入源码仓库；编译好的应用仅随 Release 提供。

## 运行

打开随附的 **FileDock.app**。支持 macOS 13 及以上；交付的通用二进制包含 Apple Silicon 与 Intel 架构，使用独立图标和本机配置目录。作者：**Diexie**。

- 鼠标移到设置中的触发位置，或默认按 **⌘⌥↓** 呼出；**⌘⌥→** 在光标附近呼出。两组全局快捷键都可在「设置 → 快捷键」中点击录制、清除或恢复默认。
- 真实刘海屏上，以固定系统箭头的可见轮廓判定，至少75%进入刘海后才开始悬停计时；透明留白和临时光标形状不影响判定，擦过边缘不累计，移出后重新计时。无刘海屏的顶部中央及四角触发方式保持原有规则。
- 刘海呼出从顶部向下舒展，连接处与面板连续衔接；收起沿原路缩回。设置为四角触发时，鼠标、菜单栏和普通呼出快捷键均从对应角落显示，避开菜单栏与 Dock，并保留移入面板的通道。**⌘H** 收起窗口。
- 从刘海或角落拖出窗口后会自动固定，移开鼠标不收起。刘海模式拖回顶部中央并松手后重新连接；再次从触发位置呼出时解除自动固定，手动设置的固定状态则保留。
- 「设置 → 外观 → 背景主题」可选择**液态玻璃**，固定为深色半透明玻璃、柔和模糊与边缘高光，不随系统明暗切换。纯色主题仍保留跟随系统、浅色、深色选项。macOS 26 使用原生玻璃，较早系统使用系统模糊材质，开启“减少透明度”时采用易读的实色背景。
- 「设置 → 通用 → 顶部展开样式」可切换 **曲线衔接** 与 **刘海嵌入**。后者使面板贴到屏幕顶部，工作区按保存顺序从刘海左侧续排到右侧，右侧仍保留添加/关闭按钮和窗口拖动空白；窗口较窄时，整排操作区会下移避开刘海。嵌入顶栏会自动滚到选中的工作区，分栏中的较长名称在可用宽度内省略显示。
- 菜单栏图标左键切换面板，右键打开设置、帮助与退出菜单。
- 点击右上角 **＋** 添加文件夹工作区，或创建文件引用合集；悬停提示“添加工作区”。首次启动提供「应用程序」与空「收藏」。当前路径显示在底栏。
- **＋ → 最近使用** 可直接添加系统最近文件工作区，再次添加会选中已有标签。最近打开的文件自动排在前面；支持搜索、预览和拖出，根目录不接收拖入或手动排序，也不改变其他工作区的排序。
- 顶部工作区标签可左右拖动排序，放在目标标签的左半边或右半边决定前后位置，插入线会提示位置；顺序自动保存。拖动时暂停悬停切换及自动收起，拖动标签不会移动窗口。
- 收藏默认固定为右上角的星标，不占用滚动标签栏。右键星标可隐藏入口，收藏会回到标签栏；通过「＋ → 固定收藏到右上角」恢复，引用内容不变。右键任意工作区标签可切换「仅显示图标」，名称仍保留在悬停提示中，显示方式自动保存。
- 收藏旁的**暂存区**可接收文件拖入，也可从文件右键菜单暂存。暂存只记录引用，清空或移除不会删除原文件；可以拖出到其他应用，或批量复制/移动到指定文件夹。通过应用内批量操作成功转移的项目移出暂存，失败项目保留；同名文件自动改名。拖到外部应用后引用仍保留，可手动移除。可从「设置 → 通用 → 文件」或加号菜单关闭入口，暂存内容继续保留。
- 暂存支持任意类型的本地文件、文件夹与文稿包。有本地地址的项目直接保存引用；浏览器拖来的图片或其他应用提供的临时文件，会先保存到本机 `~/Library/Application Support/FileDock/Staged Imports/`，再加入暂存。清空只移除引用，这些导入文件仍保留，可右键在访达中显示。
- Finder 中修改文件夹颜色、标签或自定义图标后，面板的定时刷新会同步更新。大目录的定时扫描在后台运行；批量暂存和调整窗口大小会合并配置保存。
- 「设置 → 通用 → 自动呼出例外」可添加游戏、播放器等应用。它们在前台时暂停鼠标自动呼出；也可开启「全屏时暂停鼠标呼出」。通过系统全屏状态和已有辅助功能权限识别全屏窗口；普通最大化窗口不算全屏。自定义无边框游戏或播放器若未报告全屏，可将应用加入黑名单。快捷键和菜单栏仍可手动呼出。
- 导航栏显示当前目录的逐级路径，点击任一级可跳转；较长路径可横向滚动，末级目录保持可见。收藏合集显示合集名称，进入其中的文件夹后可点击合集名称返回；前进、后退保留路径跳转记录。
- 双击打开，空格快速查看；支持网格、列表和分栏。分栏右侧直接预览选中文件，可在预览区滚动阅读；顶部提供放大预览和默认应用打开。格式支持取决于系统 Quick Look 及已安装的预览扩展。
- 文件夹模式中，拖入默认移动，按住 **Option** 则复制；合集根目录只添加引用。
- 文件名冲突会自动改名；移到废纸篓需要确认。合集菜单中的「移除引用」不删除原文件。
- **⌘C** 复制所选文件，**⌘V** 粘贴，**⌘⌥C** 复制路径；**⌘⇧[ / ]** 切换工作区。
- **⌘↑** 返回上级并选中刚离开的文件夹，接着 **⌘↓** 可重新进入；选中文件时 **⌘↓** 用默认应用打开。**⌘[ / ]** 或 **⌥← / →** 按导航历史后退、前进。搜索输入和文档预览获得焦点时保留其原生键盘操作。
- 文件可在当前目录或合集内拖动排序，拖到空白处放在末尾；顺序保存在工作区中，不移动原文件。可将单个或多个选中文件拖到访达等其他应用。排序菜单可切换回名称、日期等自动排序。
- 从顶部空白处拖动窗口，边缘可调整大小。设置包含主题、背景颜色、文字/图标大小、展开及收起延迟、触发位置、副屏、滚动方向及登录启动。
- 「设置 → 外观 → 动画」可调节 **0.5×–2.0×** 速度，也可选择舒缓、标准、轻快或迅捷。
- 面板集成 **QQ 音乐**控制：曲线衔接和普通悬浮窗口使用底部播放栏；刘海嵌入时，中央显示曲名和歌手，悬停后切换为上一首、播放/暂停、下一首，右键可打开播放器。未连接时显示连接、打开或重试入口；中央空间不足时在顶栏下方显示紧凑控制。可在「设置 → 音乐」关闭音乐控制。
- 图片和网页图片可拖入文件夹，保存为 PNG；网页下载不使用浏览器登录状态。图片限制为 32 MiB 输入、单边 8192 像素及 2400 万像素。

关闭面板后应用仍在菜单栏运行；再次打开 `.app` 也可恢复面板。若其他应用占用快捷键，设置页会显示注册失败提示，可重新录制或通过菜单栏操作。录制时至少组合 ⌘、⌃ 或 ⌥ 之一，Esc 取消、Delete 清除；新绑定自动保存。录制期间暂停原快捷键，避免旧绑定抢占输入。

## 从源码构建

需要包含 AppKit 26 的 macOS SDK（Xcode 26 或对应 Command Line Tools）与 Swift 编译器；运行目标仍是 macOS 13 及以上。不依赖第三方包或完整 Xcode 工程。

```sh
./setup-signing.sh      # 首次在本机建立固定签名身份，之后只校验并复用
./build.sh              # 当前机器架构
./build.sh --universal  # Apple Silicon + Intel
./test.sh               # 文件、图片、动画、悬停、拖拽、快捷键、窗口层级、内嵌预览与音乐测试
./test-signing.sh       # 固定签名的跨构建身份与拒绝错误身份检查
```

产物位于 `build/FileDock.app`，使用固定本地证书签名，未进行 Apple 公证。安装时替换 `/Applications/FileDock.app`，不要保留额外可启动副本。登录启动应从稳定安装位置启用。

从 1.8 起，签名私钥保存在当前用户的登录钥匙串中，设为敏感、不可导出，并仅允许系统 `/usr/bin/codesign` 使用；公共证书及身份配置位于 `~/Library/Application Support/FileDock/Signing/`，不放入源码或应用包。签名身份同时约束 bundle ID 与固定证书指纹，符合 Apple 的[代码身份与更新要求](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。初始化不会添加系统根信任。构建在签名身份缺失或配置不一致时停止，不自动生成新身份，也不退回临时签名。

从旧临时签名迁移到固定证书时，需刷新一次原应用的辅助功能授权。随后本机使用同一证书和 bundle ID 的更新沿用同一身份；更换电脑、删除钥匙串中的私钥或重置系统隐私权限后仍需重新授权。请保留原有登录钥匙串及 Signing 配置；后者不包含私钥，不能单独恢复签名身份。

1.4 版将连接处改成单段连续曲线，平滑衔接刘海侧边与面板顶边，去掉内收腰部、侧面鼓包和横向超调。标准速度展开约 **0.30 秒**、收起约 **0.22 秒**；调节倍率时，连接处和面板同步变速。文字和图标固定位置、由遮罩揭开，动画期间关闭窗口缓存阴影。快速重复触发接续当前形状。连接宽度读取显示器的刘海区域，无刘海屏幕使用顶部中央连接。系统开启「减少动态效果」时固定使用不超过 0.10 秒的淡入淡出。上述时长是动画参数，没有将其等同于实测屏幕帧率。

在「设置 → 通用 → 悬停多久后展开」中可直接输入 **0–1500 毫秒**，也可选择「即时 0ms」「灵敏 120ms」「稳妥 300ms」。0ms 表示进入区域立即触发，没有额外最低等待；新安装默认 120ms，已有设置保持。真实刘海以箭头可见面积判定；无刘海屏的顶部中央和四角保留50毫秒边缘容差。面板先展开已有内容，再刷新目录。

1.5 版新增「设置 → 通用 → 鼠标移开多久后收起」，可调 **0–3000 毫秒**，默认保持原有 550ms，并提供即时、标准和宽松预设。返回面板会取消倒计时；拖拽、调整窗口大小、固定、设置、菜单和对话框期间暂停自动收起。快捷键呼出后尚未进入面板时，仍保留原有的焦点保护。

1.6 版新增刘海嵌入样式，按屏幕真实刘海宽度预留中央区域，面板顶边直接贴合物理屏幕顶部；旧配置继续使用曲线衔接。嵌入模式从中央向两侧及下方揭开，仍使用已有动画速度与收起延迟设置。拖动窗口后恢复普通悬浮外观；光标旁呼出保持悬浮样式。无刘海显示器也可使用贴顶布局。

设置打开时浏览面板暂降至相同悬浮层级，新开的设置会置前；打开新增工作区、添加文件、自定义图标、打开方式或配置导入/导出的选择窗口时，背景面板暂时让位。对话框关闭后恢复层级，期间暂停悬停呼出与面板切换，并让文件选择器接收其原生键盘操作。

1.9 版将分栏右侧的信息卡改为原生文件内容预览，占满剩余宽度与内容区高度。选中文件后直接加载，不必先点击快速查看；重复刷新列表不会重置当前阅读位置。面板收起后释放预览项目，重新展开时尝试恢复该文件的阅读状态，音视频不自动播放。普通文件夹仍由目录导航浏览；系统无法预览的格式可使用顶部按钮在默认应用中打开。

1.10 版仅在实际贴顶的刘海嵌入模式中把音乐控制移至顶栏，并移除底部播放栏。组件高20pt，横向使用中央可用宽度，默认单行显示曲名和歌手，超长内容自动滚动（系统开启减少动态效果时保持静止）；悬停后快速淡入控制按钮，移开恢复歌曲信息。键盘焦点或旁白开启时也显示控制。按钮从屏幕安全区域下方开始布局，顶栏按需留出空间，避免被物理刘海遮挡；窄窗、无刘海或中央宽度不足时，使用安全顶栏下方的独立紧凑行。拖离顶部或在光标旁呼出后恢复底部播放栏。右上角添加工作区入口精简为单个加号，悬停说明和原菜单保持可用。

1.11 版新增「最近使用」。它是系统索引提供的虚拟集合，不能在文件选择器中作为普通目录选中，因此从加号菜单直接添加。当前查询用户目录中已索引的最近文件，最多显示500项，按最近打开时间而非修改时间排序；隐藏文件、应用及非文档目录不会出现，文件提供方和索引状态可能使结果与 Finder 的最近使用不完全相同。支持 Pages、Keynote 等文稿包；已知未下载的云端项目显示占位，不自动请求缩略图或内容预览，用户点击打开后才由系统处理下载。

QQ 音乐首次连接需要在「系统设置 → 隐私与安全性 → 辅助功能」中允许 **FileDock**，应用只在点击连接时请求此权限。从本机 QQ 音乐的原生播放栏读取曲目信息，通过其「播放控制」原生菜单执行命令；未运行、未授权或无法识别控件时，会显示对应提示。曲目信息只在面板或音乐设置窗口显示时刷新，不保存收听记录。本机 QQ 音乐 11.9.1 已实际验证播放和暂停；上一首、下一首通过模拟测试，未在验证中切换用户曲目。QQ 音乐更新界面、关闭主窗口或切换迷你播放器后，可能需要打开 QQ 音乐主窗口再连接。“重新连接”只重试读取，不重复请求系统授权；授权的启用/撤销会被轮询自动识别，正在执行控制时不再排队重复切换。

## 数据与实现范围

1.16 起使用 FileDock 数据目录和应用标识；首次运行自动迁移旧目录。继续复用原签名证书，但应用标识变更可能需要一次新的系统授权。配置在 `~/Library/Application Support/FileDock/config.json`，包含工作区路径、书签和设置，权限为 `0600`。文件留在原文件系统中；「导出工作区配置」会导出路径和书签，适合本机备份。应用不包含遥测、订阅或账号服务。只有用户拖入网页图片 URL 时才发起网络下载。

最近使用的查询结果只保存在内存中，不写入工作区配置或导出文件。退出应用或切离该虚拟根后会停止查询；索引未返回结果时，界面显示加载、空白或失败提示，可点击刷新重试。
